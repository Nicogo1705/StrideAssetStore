**Community Stride Asset Store — an unofficial, decentralized asset index for Stride**

<https://nicogo1705.github.io/StrideAssetStore/>

I've been building a place to find and install Stride assets, and it's now at a point where it's
genuinely usable. It is **not affiliated with the Stride project** — it's a community side project,
built so it *could* be handed over or pointed at a community org later with configuration alone.

**Nothing is hosted.** Every asset stays in its author's own public Git repo. The store is an index:
a JSON catalogue generated by CI, plus tooling that clones the right commit into your game. No
account, no upload, no server to trust.

**Three ways to use it**

Command line — nothing to download:
```
dotnet tool install -g StrideAssetStore
cd your/game
strideassetstore search grass
strideassetstore add grass
```
It finds your `.sln`/`.csproj`, clones the asset and its dependencies, verifies the content hash
against the registry, and adds the reference. Then `list`, `update`, `remove`.

Desktop app — a local UI with an install wizard, project manager and publishing flow (Windows,
Linux, macOS): <https://github.com/Nicogo1705/StrideAssetStore/releases/latest>

Or just browse the site.

**What it actually checks**
• the registry pins a **commit** and a deterministic **SHA-256 of the asset's content** — re-verified
after cloning, so a moved tag doesn't slip through
• **certified** versions are reviewed, immutable commit pins; community assets are listed too and
clearly marked
• every certified asset is verified to **restore and compile from nuget.org alone** — the whole
catalogue currently targets `Stride.Engine 4.4.0-beta5`
• `--stride <version>` retargets an asset to whatever build your game is on

**Publishing is a pull request adding one JSON file.** You keep your repo, your license and your
release cadence: <https://github.com/Nicogo1705/AssetContainer/blob/main/CONTRIBUTING.md>

There are 8 assets in there right now, all mine — grass, procedural sky, marching cubes, Avalonia UI
in Stride, dependency injection, and a few texture packs. It would be much more interesting with
yours. Feedback and breakage reports very welcome.

MIT, everything open: <https://github.com/Nicogo1705/StrideAssetStore>
